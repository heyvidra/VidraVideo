### 🚀 What's New

这一版主要修追更和链接下载里的问题。**从 1.16.x 升级不需要迁移数据。**

**追更**

- **更新检查现在真的去问片源了。** 之前定期的逐部检查读的是本地缓存的详情，查不出更新；有时还会把旧的集数当成新更新通知一遍。
- **从片库卡片追更后，详情页的按钮失灵。** 部分片源的卡片不带年份，详情页带。从卡片追更的剧，进到详情页却显示"订阅"，点了没反应，也没法从这里取消。已修复。
- **在两个片源之间来回浏览会反复提醒。** 同一部剧在不同片源的进度写法不同，被误当成了更新。
- **通知弹了，追更页却没有红点。** 后台巡检同时拿到多个片源的列表时，刚记下的更新会被覆盖回去，下次巡检再通知一遍。

**链接下载**

- 解析不出具体分辨率的链接，默认清晰度曾经是"仅音频"，直接点下载会得到没有画面的文件。现在默认是"最佳"。
- 同一个链接再次点下载，之前提示"已加入下载列表"但其实什么都没发生。现在会如实提示它已经在列表里；要换清晰度或重新下载，请先在"下载"里删掉原来的任务。

**窗口**

- 在当前窗口播放时，可以按住顶部拖动窗口了，双击可最大化。
- 小屏幕且系统缩放较高的电脑上，主窗口曾经缩不小（最小尺寸等于整个屏幕），已修复。
- Windows 上，窗口内播放页的返回按钮不再多缩进一截。

### 🐛 Known Issues

- 4 核及以下的 Windows 电脑默认在当前窗口播放（1.16.8 起）。如果播放异常，可在 设置 → 播放器打开方式 里改成"新窗口"。这条路径和本版的 Windows 改动都未在 Windows 真机上验证。
- 在当前窗口播放时，Windows 上没有最小化和关闭按钮，请用任务栏，或先点返回。
- 独播库上的追更只能靠浏览片库时发现更新，定期检查对它无效。
- 播放出错时的提示框里，错误描述是英文（例如 "Video source unavailable"）。
- 新装或系统更新后，第一次打开详情页可能卡一下（macOS）。这是渲染器首次编译着色器造成的，之后不再出现。
- 升级前收藏 / 看过的爱壹帆条目，封面图仍指向旧域名，可能显示不出来。
- LG 电视有间歇性的投屏失败：失败时电视上会弹出 "this file cannot be recognised"，这个框不关掉之后的投屏都会失败，需要用遥控器关掉再试。
- AirPlay 只在 macOS 上可用。
- Intel Mac 构建未经真机验证（开发机为 Apple 芯片）。
