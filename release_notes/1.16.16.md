### 🚀 What's New

**这一版会升级本地数据库。** 升级在首次启动时自动完成，已有的下载、观看记录、追更和想看都会保留。升级后请不要再装回 1.16.15 或更早的版本。

**下载的剧放错片**

下载任务以前只记一个数字编号，不记它来自哪个片源，而不同片源上同一个编号是两部不同的剧。于是会出现：

- 在"下载"里点播放，打开的却是另一部剧，而且是在线播放而不是播下好的文件。常见于下载之后切换过当前片源。
- 第二部剧被并进第一部的下载任务，标题和封面都是第一部的。
- 详情页的分集格上出现了别的剧的下载标记。

现在下载任务会记录片源。升级前下载的任务没有这项信息，仍然照常显示和播放，并会在下次给它添加分集时补上。

**关掉某个片源后，"在该片源打开"会打开错误的剧**

片源被关掉后，程序曾悄悄改去当前片源查，把查到的另一部剧存成了原片源的数据。现在片源不可用时只使用已有的本地数据。同一个原因也会让已关闭片源上的追更收到错误的更新提醒，一并修复。

**用链接下载的视频，断网时播不了**

这类视频没有对应的片库条目，播放时却仍会去片库查一次，片库连不上就直接报错。现在不再查询，离线也能播放已下载的文件。

**投屏到三星电视，续播位置越来越靠后**

从上次的位置继续投屏时，播放位置被多算了一次续播起点，每投一次错得更多。已修复。

**切换分集后，上一集的进度没记上**

拖动进度条后很快切到下一集，上一集最后的位置会丢。已修复。

### 🐛 Known Issues

- 投屏到 LG 或三星后，直接关电视或最后一集播完，App 仍会显示"正在投屏"，电脑也不会自动休眠。请手动点停止。
- 4 核及以下的 Windows 电脑默认在当前窗口播放（1.16.8 起）。如果播放异常，可在 设置 → 播放器打开方式 里改成"新窗口"。这条路径和近期的 Windows 改动都未在 Windows 真机上验证。
- 在当前窗口播放时，Windows 上没有最小化和关闭按钮，请用任务栏，或先点返回。
- 独播库上的追更只能靠浏览片库时发现更新，定期检查对它无效。
- 播放出错时的提示框里，错误描述是英文（例如 "Video source unavailable"）。
- 新装或系统更新后，第一次打开详情页可能卡一下（macOS）。这是渲染器首次编译着色器造成的，之后不再出现。
- 升级前收藏 / 看过的爱壹帆条目，封面图仍指向旧域名，可能显示不出来。
- LG 电视有间歇性的投屏失败：失败时电视上会弹出 "this file cannot be recognised"，这个框不关掉之后的投屏都会失败，需要用遥控器关掉再试。
- AirPlay 只在 macOS 上可用。
- Intel Mac 构建未经真机验证（开发机为 Apple 芯片）。
