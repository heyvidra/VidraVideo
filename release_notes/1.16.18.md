### 🚀 What's New

**Windows 用户请留意：从这一版起，Windows 上的"发送诊断数据"会真正生效。** 从 1.16.x 升级不需要迁移数据。

**Windows：诊断数据开关现在说到做到**

设置里一直有"发送诊断数据"这个开关，默认开启。但由于构建上的疏漏，此前所有 Windows 版本无论开关如何都不会发送任何内容。这一版修正了这一点：

- 开关**开着**的 Windows 用户，从这一版起会开始发送诊断数据。
- 发送的内容和 macOS 一致：帧率、机型与系统版本、投屏协议阶段与错误码。**不包含你看了什么**——没有片名、搜索词、播放地址和文件路径。
- 不想发送的话，在 设置 → 诊断 里关掉即可，关掉后不会发送任何内容。

Windows 上目前只上报流畅度数据和程序错误，暂不包含整个程序闪退的记录。

macOS 用户不受影响，行为和之前一样。

**在当前窗口播放，退出后续播位置不对**

在当前窗口播放的模式下，返回时最后的播放位置会晚几秒才保存。期间回到详情页看到的还是旧进度；如果这几秒内退出 App，这次保存就丢了。已修复。

**其他**

- 诊断功能即使启动失败，也不再影响 App 本身的启动。

### 🐛 Known Issues

- Android TV：播放出错时屏幕上的"重试"按钮用遥控器按不到，需要返回后重新进入；片源列表里的"爱壹帆"在 Android TV 上无法使用。
- 投屏到 LG 或三星后，直接关电视或最后一集播完，App 仍会显示"正在投屏"，电脑也不会自动休眠。请手动点停止。
- 4 核及以下的 Windows 电脑默认在当前窗口播放（1.16.8 起）。如果播放异常，可在 设置 → 播放器打开方式 里改成"新窗口"。这条路径和近期的 Windows 改动都未在 Windows 真机上验证。
- 在当前窗口播放时，Windows 上没有最小化和关闭按钮，请用任务栏，或先点返回。
- 独播库上的追更只能靠浏览片库时发现更新，定期检查对它无效。
- 播放出错时的提示框里，错误描述是英文（例如 "Video source unavailable"）。
- 新装或系统更新后，第一次打开详情页可能卡一下（macOS）。这是渲染器首次编译着色器造成的，之后不再出现。
- 升级前收藏 / 看过的爱壹帆条目，封面图仍指向旧域名，可能显示不出来。
- LG 电视有间歇性的投屏失败：失败时电视上会弹出 "this file cannot be recognised"，这个框不关掉之后的投屏都会失败，需要用遥控器关掉再试。
- AirPlay 只在 macOS 上可用。
- Intel Mac 构建未经真机验证（开发机为 Apple 芯片）。
