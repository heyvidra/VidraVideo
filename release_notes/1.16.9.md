### 🚀 What's New

本版继续做流畅度，这次是先实测再改。**从 1.16.x 升级不需要迁移数据。**

**片库滚动更顺**

实测发现滚动时大部分时间花在排版文字上，而每张卡片有一块鼠标悬停才显示的信息面板，平时看不见却一直在参与排版。现在改为鼠标移上去时才生成。在开发机上同一段滚动，掉帧数降到原来的四分之一左右。外观和悬停效果不变。

**其他**

- 主窗口的背景只绘制一次，不再跟着窗口里的每次变化重画。
- macOS 主窗口不再向系统申请"窗口后模糊"：它一直被不透明背景盖着，看不到，系统却每帧都在计算。
- "标记为已看"改为一次写入，集数多的剧不再卡一下。
- 减少特效开启时，封面不再淡入。

### 🐛 Known Issues

- 新装或系统更新后，第一次打开详情页可能卡一下（macOS）。这是渲染器首次编译着色器造成的，之后不再出现；彻底解决要等 Flutter 上游修复后切换渲染器。
- 1.16.8 起的 Windows 改动（自动减少特效、Ctrl 快捷键）仍未在 Windows 真机上验证。
- 升级前收藏 / 看过的爱壹帆条目，封面图仍指向旧域名，可能显示不出来。
- LG 电视有间歇性的投屏失败：失败时电视上会弹出 "this file cannot be recognised"，这个框不关掉之后的投屏都会失败，需要用遥控器关掉再试。
- AirPlay 只在 macOS 上可用。
- Intel Mac 构建未经真机验证（开发机为 Apple 芯片）。
