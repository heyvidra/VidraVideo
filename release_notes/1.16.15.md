### 🚀 What's New

这一版修下载里的五个问题。**从 1.16.x 升级不需要迁移数据，已经下载好的文件不受影响。**

**同名的两部剧会互相覆盖文件**

下载的文件名只有"片名_集名"。如果先后下载两部同名的剧（翻拍版，或同一部剧换了片源），后下载的会删掉先下载的文件再写上自己的，于是旧任务显示"已完成"，点开却是另一部剧。同一部剧里"第12集"和"第12集(粤语)"也会写进同一个文件。

现在后来的那个下载会在文件名末尾多一小段区分码，先下载的保持原名。

**暂停再继续，同一集可能下载两遍**

一集下载失败后会等几秒自动重试。在这几秒里按暂停再继续，旧的重试会在后台把整集悄悄下完（界面显示"排队中"、没有进度，却占着一个下载名额），然后再从头下一遍。已修复。

**取消过的集再点下载，提示"已添加"却没有开始**

取消或失败的集，在详情页的下载模式里再点一次，之前只弹提示不干活。"全部取消"之后再点"全部下载"也一样。现在会重新排队。

**"全部下载"下错了片源**

在详情页切换到另一个片源查看分集时点"全部下载"，之前下载的是页面原本那个片源的。现在下载的是屏幕上正在显示的那个。

**转码失败重试时一直显示"转码中"**

之前整个重新下载的过程都显示"转码中"，看不到速度和剩余时间。已修复。

### 🐛 Known Issues

- 4 核及以下的 Windows 电脑默认在当前窗口播放（1.16.8 起）。如果播放异常，可在 设置 → 播放器打开方式 里改成"新窗口"。这条路径和近期的 Windows 改动都未在 Windows 真机上验证。
- 在当前窗口播放时，Windows 上没有最小化和关闭按钮，请用任务栏，或先点返回。
- 独播库上的追更只能靠浏览片库时发现更新，定期检查对它无效。
- 播放出错时的提示框里，错误描述是英文（例如 "Video source unavailable"）。
- 新装或系统更新后，第一次打开详情页可能卡一下（macOS）。这是渲染器首次编译着色器造成的，之后不再出现。
- 升级前收藏 / 看过的爱壹帆条目，封面图仍指向旧域名，可能显示不出来。
- LG 电视有间歇性的投屏失败：失败时电视上会弹出 "this file cannot be recognised"，这个框不关掉之后的投屏都会失败，需要用遥控器关掉再试。
- AirPlay 只在 macOS 上可用。
- Intel Mac 构建未经真机验证（开发机为 Apple 芯片）。
