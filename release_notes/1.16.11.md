### 🚀 What's New

一批界面和文案修复。**从 1.16.x 升级不需要迁移数据。**

**"撤销"按钮的文字**

从"继续观看"里移除一条记录后，提示条上的撤销按钮从 1.16.8 起显示成了 `common.undo`。按钮功能一直正常，只是文字错了，现已修复。

**电影详情页不再按电视剧的说法写**

- 分集区的标题由"剧集"改为"正片"。
- 不再显示"1 集未看"和片源标签上的"1 集"。
- 进度标记由"看到 576P"改为时间点，例如"看到 0:18"。
- 讲集号规则的那行提示不再出现在电影页。

电视剧、综艺、动漫不受影响。

**其他**

- 详细信息里，片源没有提供的项目不再显示"未知"，直接不显示。
- 搜索结果页的侧栏不再高亮"首页"。
- 爱壹帆的三条报错（连接失败、人机验证、访问过于频繁）在英文界面下显示英文。
- 英文界面：侧栏的 Continue 与页面标题统一为 Continue Watching。
- macOS：菜单栏去掉了一个点不了的 Preferences 菜单项。设置仍可用 ⌘, 打开。

### 🐛 Known Issues

- 播放出错时的提示框里，错误描述是英文（例如 "Video source unavailable"）。
- 新装或系统更新后，第一次打开详情页可能卡一下（macOS）。这是渲染器首次编译着色器造成的，之后不再出现。
- 1.16.8 起的 Windows 改动（自动减少特效、Ctrl 快捷键）仍未在 Windows 真机上验证。
- 升级前收藏 / 看过的爱壹帆条目，封面图仍指向旧域名，可能显示不出来。
- LG 电视有间歇性的投屏失败：失败时电视上会弹出 "this file cannot be recognised"，这个框不关掉之后的投屏都会失败，需要用遥控器关掉再试。
- AirPlay 只在 macOS 上可用。
- Intel Mac 构建未经真机验证（开发机为 Apple 芯片）。
