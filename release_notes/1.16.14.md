### 🚀 What's New

修五个问题，都是日常会碰到的。**从 1.16.x 升级不需要迁移数据。**

**搜索历史重启后就没了**

搜索历史和设置存在一起，而保存设置时会把它一并清空。切换主题、切换片源，甚至只是关掉播放器窗口（会保存窗口大小），都会触发。现在保存设置不再动搜索历史。

同一个原因还让追更"20 分钟内不重复检查"的限制在重启后失效，一并修复。

**关掉播放器，下次续播的位置不对**

关闭播放器窗口时，最后的播放位置没有存上，续播会落后几秒到十几秒；如果刚拖动完进度条就关掉，会回到拖动之前的位置。现在关闭前会先保存。

**看完回到详情页，"继续观看"还是之前那一集**

详情页开着的时候去播放，播放器播到了后面的集数，回来后详情页仍然显示之前那一集，点了也是打开之前那一集。现在播放结束后详情页和"继续观看"列表会刷新。

**搜索带特殊符号的片名会出错**

搜索 "Fate/Zero"、"22/7" 这类带斜杠的片名会打不开结果页，带 # 或 ? 的搜索词会被截断。已修复。

**在设置里点一下开关，播放器窗口的位置被还原**

调整过播放器窗口的大小或位置后，再去设置里改任何一项，播放器下次打开又回到了原来的大小和位置。桌面宠物的位置也有同样的问题。已修复。

### 🐛 Known Issues

- 已经丢失的搜索历史无法恢复，从这一版起重新积累。
- 4 核及以下的 Windows 电脑默认在当前窗口播放（1.16.8 起）。如果播放异常，可在 设置 → 播放器打开方式 里改成"新窗口"。这条路径和近期的 Windows 改动都未在 Windows 真机上验证。
- 在当前窗口播放时，Windows 上没有最小化和关闭按钮，请用任务栏，或先点返回。
- 独播库上的追更只能靠浏览片库时发现更新，定期检查对它无效。
- 播放出错时的提示框里，错误描述是英文（例如 "Video source unavailable"）。
- 新装或系统更新后，第一次打开详情页可能卡一下（macOS）。这是渲染器首次编译着色器造成的，之后不再出现。
- 升级前收藏 / 看过的爱壹帆条目，封面图仍指向旧域名，可能显示不出来。
- LG 电视有间歇性的投屏失败：失败时电视上会弹出 "this file cannot be recognised"，这个框不关掉之后的投屏都会失败，需要用遥控器关掉再试。
- AirPlay 只在 macOS 上可用。
- Intel Mac 构建未经真机验证（开发机为 Apple 芯片）。
