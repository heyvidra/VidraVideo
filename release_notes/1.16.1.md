### 🚀 What's New

下载引擎升到 vidraDlp 0.5.1，全是修复。**从 1.16.0 升级不需要迁移数据**——这一版只换了下载引擎，启动即用。

**下载的视频音画不同步**

之前下载转存 MP4 时，整条时间轴是从头重建的，而且三处都建错了：源里音频和画面的起始偏移被直接丢掉（声音恒定早或晚一截）；44.1kHz 音轨的每帧时长被取整，每小时累计约 0.35 秒漂移，一集看到结尾嘴型就对不上；视频全片摊一条平均帧时长，23.976fps 的片每小时再慢 0.7 秒，广告拼接点的时间戳跳变还会被抹平进整部片。现在三者都按源的真实时间戳来：起始偏移逐 tick 保留，音轨用自己的采样率计时，视频逐帧写真实时长，拼接点最多损一帧。

**已下载的旧文件不会自动修复——时间轴错误已经写进文件里了，重新下载才是新引擎的产物。**

**加密源只有开头几秒正常**

整表加密的 HLS 源只解密了第 0 段，其余段被原样写盘。现在密钥按规范沿用到它管辖的每一段。

**带广告的源看到一半黑屏**

广告拼接（SSAI）更换流 ID 后，后面的内容被整段静默丢弃。现在跟着切换；引擎无法转存的广告段（HEVC/AC-3）仍会跳过，代价从"后面全没了"降到一帧。

**断点续传更稳**

CDN 轮换鉴权 token 后的重试不再被误判成"不同文件"而从头下载；从错误偏移续传的响应会被拒绝并重试，而不是拼进文件；换了内容的地址会干净地重新开始。
