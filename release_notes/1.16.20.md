### 🚀 What's New

从 1.16.x 升级不需要迁移数据。

**片库：点了哪个分类，就显示哪个分类**

片库还在加载时切换分类、筛选或片源，有时显示的仍是上一个分类的内容，往下滚还会跳过新分类的第一页。已修复。

**继续观看更准了**

- 在片尾关掉某一集后，从"最近播放"或右键菜单点"继续"，现在会直接播下一集，不再停在已看完那一集的"是否重播"提示上。
- 独播库：某一集的地址临时取不到时，这一集不会再从列表里消失。此前它一消失，后面每一集的观看进度都会错位到相邻的那一集上。
- 重新点播放器正在播的那部剧的某一集，现在一定会切过去（此前自动连播之后再点最初那一集没有反应）。

**网络不好时不再丢内容**

- 详情页刷新失败时，已经缓存的剧集列表不会被清空，也不会显示成"未找到"。
- 片源临时返回空结果时，不会再被记住十分钟；点刷新会真正重新请求。
- 详情页加载失败时有"重试"按钮了。
- 从"最近播放"里移除、或清空历史后，仍在"想看"和"追更"里的剧不会再打不开。

**设置**

- 在设置里开关任意片源，不会再把当前片源切回启动时的那个。
- 右键菜单里的"在其他片源打开"现在会出现了。
- 搜索 "." 或 ".." 不再跳到别的页面。
- 清理缓存时，遇到占用中的文件会跳过继续清，而不是就此停下。

**窗口**

- Windows：播放器最小化时关闭，下次打开不再丢失窗口大小和位置。
- 设置数据读取失败时，App 会用默认设置启动，而不是白屏。
- 在当前窗口播放时不再提供画中画。此前它缩小的是整个主窗口，并且会留下错误的窗口尺寸。需要画中画请把 设置 → 播放器打开方式 改成"新窗口"。

**英文界面**

- 集数标签跟随界面语言（"Ep 5" 而不是 "第5集"）。

### 🐛 Known Issues

- 这一版起构建工具从 Flutter 3.47 升级到 3.50。macOS 版在开发机上构建通过，但各平台安装包未做装机验证；如果启动或窗口表现异常，请退回 1.16.19。
- macOS：用系统菜单或绿色按钮进入全屏后，再用播放器自己的全屏按钮，两者可能反着来。请只用其中一种方式。
- macOS：开着桌面宠物时，宠物冒泡提醒的那一刻播放器的键盘快捷键会失效，点一下播放器即可恢复。
- 1.16.19 的投屏改动仍未在真实电视上逐一验证。如果换电视投屏时出现异常，请先手动点停止再投。
- 首次连接的三星电视可能配对不上并投屏失败，表现为电视上弹出的允许提示来不及点。重试一次通常可以。
- 投影仪和电视的 Miracast 不受支持（macOS 本身不提供这个能力）。请在设备上改用 AirPlay 或 DLNA 接收。

- Android TV：播放出错时屏幕上的"重试"按钮用遥控器按不到，需要返回后重新进入；片源列表里的"爱壹帆"在 Android TV 上无法使用。
- 投屏到 LG 或三星后，直接关电视或最后一集播完，App 仍会显示"正在投屏"，电脑也不会自动休眠。请手动点停止。
- 4 核及以下的 Windows 电脑默认在当前窗口播放（1.16.8 起）。如果播放异常，可在 设置 → 播放器打开方式 里改成"新窗口"。这条路径和近期的 Windows 改动都未在 Windows 真机上验证。
- 在当前窗口播放时，Windows 上没有最小化和关闭按钮，请用任务栏，或先点返回。
- 独播库上的追更只能靠浏览片库时发现更新，定期检查对它无效。
- 播放出错时的提示框里，错误描述是英文（例如 "Video source unavailable"）。
- 新装或系统更新后，第一次打开详情页可能卡一下（macOS）。这是渲染器首次编译着色器造成的，之后不再出现。
- 升级前收藏 / 看过的爱壹帆条目，封面图仍指向旧域名，可能显示不出来。
- LG 电视有间歇性的投屏失败：失败时电视上会弹出 "this file cannot be recognised"，这个框不关掉之后的投屏都会失败，需要用遥控器关掉再试。
- AirPlay 只在 macOS 上可用。
- Intel Mac 构建未经真机验证（开发机为 Apple 芯片）。
