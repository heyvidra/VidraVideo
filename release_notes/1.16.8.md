### 🚀 What's New

本版是一轮面向低配机器的优化，外加几处体验修补。**从 1.16.x 升级不需要迁移数据。**

**低配 Windows 机默认更省**

"减少特效"的自动档以前只认 Intel Mac，Windows 一律不降级。现在 4 个逻辑核及以下的 Windows 机默认开启。带独立显卡的 4 核机器会被一并算进去，可在 设置 → 减少特效 里改回"关"。

减少特效开启时，另外去掉了页面切换的淡入淡出、分集格的纹理和大面积阴影。没开这个开关的机器外观不变。

**片库**

- 翻页失败时，页脚会显示错误和"重试"。以前列表只是停住，看起来和"到底了"一样。
- 宽窗口上第一页填不满一屏时，会自动接着加载。以前会卡在第一页。
- 封面缓存从 200 张提到 1000 张，往回翻不再重新下载。
- 超时、断网的提示改为中文。

**下载页**

有任务在下载时，整页不再每秒重建四次。

**其他**

- 快捷键：⌘/Ctrl+F 搜索，Esc 退出搜索或返回，⌘/Ctrl+, 打开设置。
- 从"继续观看"里移除一条记录后可以撤销。
- 主窗口最小可以缩到 960×600，以前是屏幕的 60%。
- 启动时的几项初始化改为同时进行。

### 🐛 Known Issues

- 本版的 Windows 改动（自动档判定、Ctrl 快捷键）未在 Windows 真机上验证。
- 升级前收藏 / 看过的爱壹帆条目，封面图仍指向旧域名，可能显示不出来。
- LG 电视有间歇性的投屏失败：失败时电视上会弹出 "this file cannot be recognised"，这个框不关掉之后的投屏都会失败，需要用遥控器关掉再试。
- AirPlay 只在 macOS 上可用。
- Intel Mac 构建未经真机验证（开发机为 Apple 芯片）。
