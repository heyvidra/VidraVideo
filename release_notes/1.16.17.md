### 🚀 What's New

这一版主要加固"诊断数据"的隐私保护，另有几处窗口和片源的修复。**从 1.16.x 升级不需要迁移数据。**

**诊断数据：补上两处可能带出内容的漏洞**

Vidra 的承诺是：诊断数据里不包含你看了什么——没有片名、搜索词、播放地址和文件路径。所有上报内容发出前都会经过一道抹除处理。检查中发现这道处理有两处遗漏：

- 数据库写入失败时，报错信息里会附带这次要写入的内容（例如搜索历史，或加入"想看"的片名），而抹除处理不认识这种格式。
- 文件路径只抹掉了第一个空格之前的部分。下载的文件以片名命名，空格之后恰好是片名和集数。

两处都已修复。**目前没有发现这类内容被实际上报过的证据**；这是代码里存在的可能路径，需要特定的出错时机才会触发。只有在设置里开启了"发送诊断数据"的用户才会上报任何内容。

同时，主窗口和播放器窗口同时写数据库时，后到的一方现在会稍等片刻而不是立刻失败，从源头上减少这类报错。

**播放器窗口**

- 全屏时的窗口大小曾被当作常规大小保存。如果在全屏状态下 App 被强制退出，下次打开播放器会占满整个屏幕。已修复。
- 快速连续切换画中画，会把动画中途的尺寸存成画中画窗口的大小。已修复。

**片源**

- 欧乐影院返回异常内容时，详情页和搜索曾直接报出原始错误，搜索时一条坏数据会让整页结果都出不来。现在会给出正常的提示。
- 爱壹帆返回形状不同的数据时不再出错。

**其他**

- 详情页切换到另一个片源查看分集后点刷新，现在刷新的是屏幕上显示的那个片源。
- 投屏中点另一集切换失败时，现在会有提示。
- 启动后 2 秒内手动关掉的桌面宠物不会再被重新打开。

### 🐛 Known Issues

- 投屏到 LG 或三星后，直接关电视或最后一集播完，App 仍会显示"正在投屏"，电脑也不会自动休眠。请手动点停止。
- 4 核及以下的 Windows 电脑默认在当前窗口播放（1.16.8 起）。如果播放异常，可在 设置 → 播放器打开方式 里改成"新窗口"。这条路径和近期的 Windows 改动都未在 Windows 真机上验证。
- 在当前窗口播放时，Windows 上没有最小化和关闭按钮，请用任务栏，或先点返回。
- 独播库上的追更只能靠浏览片库时发现更新，定期检查对它无效。
- 播放出错时的提示框里，错误描述是英文（例如 "Video source unavailable"）。
- 新装或系统更新后，第一次打开详情页可能卡一下（macOS）。这是渲染器首次编译着色器造成的，之后不再出现。
- 升级前收藏 / 看过的爱壹帆条目，封面图仍指向旧域名，可能显示不出来。
- LG 电视有间歇性的投屏失败：失败时电视上会弹出 "this file cannot be recognised"，这个框不关掉之后的投屏都会失败，需要用遥控器关掉再试。
- AirPlay 只在 macOS 上可用。
- Intel Mac 构建未经真机验证（开发机为 Apple 芯片）。
